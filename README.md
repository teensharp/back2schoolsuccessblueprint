# Blueprint Builder Book

We are going to build fillable book for the Back-to School Success Week 2026. This is a book of pre-session assignments, notes for each session, each day, and end=of-day analysis that brings a student closer to building out a Back to School success blueprint. I'll upload the screenshots from the Vault to inform the brand alignment of the blueprint, I'll also upload the framing document. We will use live session focus column to create pages in the blueprint for guided notetaking. I'd love for these notes to pre-populate  questions for the blueprint lab but I'm not sure how affordable will be this level of interactivity for 100+ users.
